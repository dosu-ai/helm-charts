  kubectl -n {{ .Release.Namespace }} get secret {{ include "seshi.bootstrapSecretName" . }} -o jsonpath='{.data.admin-token}' | base64 -d
  kubectl -n {{ .Release.Namespace }} get secret {{ include "seshi.bootstrapSecretName" . }} -o jsonpath='{.data.org-key}' | base64 -d

Members sign in with `seshi login --server <url> --key <org key>`. Move the tokens somewhere
safe and delete the Secret when you like; seshi does not read it. With an IdP, add
config.auth.oidc and sign in through it instead.
{{- else }}
Make the first admin token and the org key once:

  kubectl -n {{ .Release.Namespace }} exec deploy/{{ include "seshi.fullname" . }} -- seshi admin init --json

A second `admin init` exits 6: the bucket already has an admin.
